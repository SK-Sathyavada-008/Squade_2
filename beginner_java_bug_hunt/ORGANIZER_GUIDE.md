# Organizer Guide

## Recommended workflow
1. Upload this repository to GitHub.
2. Check that the starter code compiles and each task has the intended bug.
3. Create one GitHub Issue per selected task using the matching Markdown file under `issues/`.
4. Add labels such as `easy`, `medium`, `java`, and `hackathon`.
5. Assign each issue to one participant/team at a time.
6. Share the repository and issue descriptions before the offline coding period.

## Important
- The issue descriptions in this ZIP are local Markdown files; GitHub does not automatically convert them into live Issues.
- These tasks are custom practice exercises, not contributions to external projects.
- The code snippets intentionally contain bugs; that is the point of the exercise.
- Students can commit locally while offline. Pushing branches and creating PRs require internet access.
